# DEN: анализ золота, серебра и AAPL

Дашборд для краткосрочной торговли: индикаторы, консенсус лонг/шорт по таймфреймам 5m, 15m, 1h, 1d и 1w (неделя), уровни поддержки и сопротивления, ориентиры стопа и целей по ATR.

## Запуск
```bash
python -m pip install -r requirements.txt
python run.py                 # то же, что streamlit run app.py; удобно для кнопки Run в PyCharm
streamlit run app.py          # реальные данные Yahoo Finance
DEN_DEMO=1 streamlit run app.py   # демо-режим на синтетических данных, без интернета
python -m den.analysis GC=F   # консенсус в консоли
python -m pytest -q           # тесты
```

## Источники данных
- **Bybit** (основной, без ключа): бессрочные фьючерсы. Контракт подбирается при запуске:
  сначала среди фьючерсов, затем среди токенов на споте (например XAUTUSDT, AAPLXUSDT),
  в зависимости от того, что сейчас торгуется. Список кандидатов в `den/data.py` (`BYBIT_CANDIDATES`).
- **Twelve Data** (запасной): золото XAU/USD, серебро XAG/USD и AAPL, свечи от 5 минут.
  Зарегистрируйтесь на [twelvedata.com](https://twelvedata.com), скопируйте бесплатный API-ключ
  и задайте его в переменной окружения `DEN_TWELVEDATA_KEY`. Бесплатный тариф: 8 запросов в минуту и 800 в день.
- **Yahoo Finance** (запасной): фьючерсы GC=F, SI=F и AAPL. Если Yahoo заблокирован, задайте прокси
  в `DEN_PROXY`, например `http://127.0.0.1:8080` или `socks5://127.0.0.1:1080`.

**История и кэш.** Bybit отдаёт не больше 1000 свечей за запрос, поэтому DEN подгружает историю
страницами: до 20 000 свечей 5m (около 70 дней), 8 000 свечей 15m (83 дня), 6 000 свечей 1h и 1 000
дневных. Свечи сохраняются в `~/.den/cache` (или в `DEN_HOME/cache`), и при следующих запусках
догружаются только новые. Первый запуск по активу занимает несколько секунд; чтобы скачать историю
заново, удалите папку кэша. Глубина задаётся в `den/data.py` (`HISTORY_BARS`).

Переменные окружения в PyCharm задаются в Run → Edit Configurations → Environment variables,
в терминале: `export DEN_TWELVEDATA_KEY=...` (macOS/Linux) или `set DEN_TWELVEDATA_KEY=...` (Windows).

## Деривативы Bybit
Для фьючерсов Bybit в консенсус добавляются три голоса из того же бесплатного API (без ключа):
- **Funding**: ставка финансирования выше обычной 0.01% за 8 часов значит, что лонгов слишком много.
  Это перегрев, голос против толпы. Отрицательная ставка голосует за лонг.
- **Open interest**: OI растёт вместе с ценой, значит заходят новые лонги (за рост); OI растёт при падении цены,
  значит заходят шорты (за снижение). Падение OI (закрытие позиций) даёт слабый голос.
- **Long/Short**: доля аккаунтов в лонге. Сильный перекос (больше 55% в одну сторону) даёт слабый голос против толпы.

У спот-токенов (например AAPLXUSDT) этих данных нет, тогда голоса не добавляются. Отключить можно
галочкой «Учитывать деривативы Bybit» в боковой панели. В проверке сигналов на истории деривативы
не участвуют: Bybit отдаёт по ним только короткую историю.

## Прогноз
- **Ожидаемый диапазон** цены на 1 час, 4 часа и сутки (68% и 95%) по недавней волатильности.
- **Проверка сигналов на истории**: как часто сигнал лонг или шорт на этом активе угадывал направление через 1 час, 4 часа и сутки.
- **Бэктест консенсуса как торговой системы**: сделки по сигналам консенсуса с комиссией (по умолчанию
  тейкер Bybit 0.055% за сторону) и проскальзыванием (0.02%), стопом и целью в ATR, выходом по развороту
  сигнала или по времени. Показывает число сделок, долю прибыльных, profit factor, итог, максимальную
  просадку и кривую капитала против «купить и держать». Параметры меняются в разделе «Параметры бэктеста»,
  из консоли: `python -m den.backtest BYBIT:GOLD 15m`.
- **Новости** из Google News RSS за 3 дня с оценкой тона каждого заголовка. Если задан ключ OpenRouter,
  тон оценивает ИИ по смыслу заголовка (галочка «Тон новостей через ИИ» в разделе «ИИ-анализ», включена
  по умолчанию): один запрос на актив не чаще раза в 30 минут (заголовки, появившиеся между запросами, оцениваются словарём).
  Без ключа или при ошибке используется словарь финансовых фраз (для металлов ставки ФРС, доллар, доходности,
  геополитика; для AAPL отчёты, рейтинги аналитиков, суды).
- **Прогнозный вердикт** объединяет технику по всем таймфреймам (60%), тон новостей (25%) и историческую
  надёжность сигнала (15%) и показывает уверенность.

## Итоговый сигнал
Поверх консенсуса DEN выдаёт один итоговый сигнал (блок «Итоговый сигнал» вверху дашборда):
- **Подтверждение старшими таймфреймами.** Направление задают 5m и 15m, они должны смотреть в одну сторону.
  Если 1h и 1d смотрят туда же, сигнал сильный и получает значок «подтверждён старшими ТФ». Если один из
  старших против, сигнал помечается «против старших ТФ» и почти никогда не проходит порог.
- **Недельный таймфрейм (1w)** задаёт фон. Если неделя против сигнала, он не бывает сильным, вклад
  подтверждения в уверенность умножается на 0.7 и вверху появляется предупреждение. Балл недели входит
  и в модель уверенности. У токенизированных контрактов Bybit недельная история короткая: пока в ней
  меньше 50 свечей, 1w просто не учитывается (дашборд пишет об этом под сигналом).
- **Семейства индикаторов.** Похожие индикаторы объединены в семейства: тренд и импульс (EMA 9/21,
  EMA 50/200, ADX/DMI, MACD), осцилляторы (RSI, стохастик, Боллинджер), объём (OBV), деривативы,
  разворот и пробой (дивергенция RSI, пробой после сжатия Боллинджера), связанный актив. Голоса
  сначала усредняются внутри семейства, затем семейства между собой, поэтому четыре трендовых
  индикатора больше не перевешивают остальные только своим числом.
- **Дивергенция RSI**: цена обновила минимум, а RSI нет (бычья), или наоборот (медвежья).
  **Сжатие Боллинджера**: канал был в самых узких 20% за 120 свечей, и цена пробила его границу.
- **Фильтр режима рынка.** На каждом таймфрейме по ADX и волатильности определяется режим: тренд
  (ADX ≥ 25 или ADX 20–25 при расширении волатильности), боковик (ADX ≤ 20 или сжатие волатильности)
  или переходный. В тренде вес семейства «тренд и импульс» умножается на 1.5, а осцилляторов на 0.5;
  в боковике наоборот. Выключается галочкой «Фильтр режима рынка» в разделе «Сигнал и риск».
- **Калиброванная уверенность.** Уверенность — это вероятность того, что цена пройдёт 1.5 ATR (15m)
  в сторону сигнала раньше, чем 1.5 ATR против, в пределах 4 часов. Её считает логистическая регрессия,
  обученная на истории этого актива (баллы 5m, 15m, 1h, 1d, 1w, подтверждение старшими ТФ, сила консенсуса).
  Пока размеченных сигналов меньше 200, работает прежняя формула: 40% сила консенсуса 5m и 15m,
  35% подтверждение старшими, 25% угадываемость. Порог по умолчанию 70%; калиброванная вероятность
  выше 70% бывает редко, на практике разумный порог 60–65%.
- **Угадываемость по стопу и цели.** Для последних 60 сигналов той же стороны на 15m проверяется,
  что сработало раньше: цель или стоп (1.5 ATR), с комиссией и проскальзыванием. Ниже минимума (55%)
  сигнал не выдаётся.
- **Защита от мигания.** Направление должно держаться две закрытые свечи 15m подряд. Уже действующий
  сигнал снимается, только когда уверенность падает на 10 п.п. ниже порога.
- **Торговые сессии.** Металлы: от открытия Лондона (08:00) до закрытия Нью-Йорка (17:00), Apple:
  основная сессия биржи США, по будням. Вне сессии токены торгуются на тонком рынке, и сигнал не выдаётся.
  Галочка «Только в основную сессию».
- **Прибыль/риск.** Стоп ставится за ближайший уровень поддержки или сопротивления (если он в 0.75–3 ATR,
  иначе 1.5 ATR), цели у следующих уровней. Если до первой цели меньше 1.5 расстояний до стопа,
  сигнал не выдаётся. Галочка «Прибыль/риск не хуже 1:1.5».
- **Связка золото–серебро.** Для металлов в консенсус добавляются консенсус второго металла и
  отклонение соотношения золото/серебро от среднего за 200 свечей (больше 1.5 σ — голос за возврат
  к среднему). Галочка «Связка золото–серебро».
- **Бэктест итогового сигнала.** Вся логика выше прогоняется по истории 15m без заглядывания в будущее:
  старшие ТФ берутся только по уже закрытым свечам, модель переобучается раз в сутки только на прошлых
  сигналах. Сделки с комиссией тейкера Bybit, проскальзыванием, стопом и целью в ATR и переносом стопа
  в безубыток после 1R. Деривативы, связка металлов и фильтр прибыль/риск в историю не входят.

## Геополитический фон
Отдельный блок, который **не голосует в консенсусе**, а предупреждает о риске и уменьшает рекомендуемый
размер позиции:
- **Индекс GPR** (Caldara & Iacoviello, [matteoiacoviello.com/gpr.htm](https://www.matteoiacoviello.com/gpr.htm)),
  дневной ряд. Если его среднее за 7 дней выше 85% дней за последний год, фон повышенный, выше 97% высокий.
  Файл кэшируется в `~/.den/gpr_daily.csv` на 12 часов. Если сайт недоступен, скачайте
  `data_gpr_daily_recent.xls` вручную и укажите путь в `DEN_GPR_FILE`.
- **Разметка новостей.** Геополитические заголовки Google News за 2 дня (войны и удары, санкции,
  пошлины, выборы, деэскалация) получают тип, силу 0–3 и влияние на золото, серебро и AAPL. С ключом
  OpenRouter разметку делает ИИ (не чаще раза в 30 минут), без ключа словарь.
- **Режим «повышенный риск».** Одно крупное событие или три заметных за сутки, влияющих на актив, либо
  высокий GPR дают повышенный риск (размер позиции 50% от обычного); крупные события вместе с высоким GPR
  дают высокий риск (25%). Вверху дашборда появляется предупреждение, в разборе таймфрейма показан размер
  позиции от «Риска на сделку» (по умолчанию 1% депозита). Предупреждение попадает и в уведомления Telegram.

## ИИ-анализ (GPT-6 Astra через Tooken Club)
Кнопка «Запросить ИИ-анализ» отправляет модели сводку DEN и показывает вероятность роста цены за 4 часа,
направление (лонг от 60%, шорт до 40%, между ними нейтрально), разбор, ключевые факторы, что сломает
сценарий, уровни входа, стопа и цели и согласие с сигналом DEN. Запрос уходит только по кнопке.

1. Создайте ключ в личном кабинете [tooken.club](https://tooken.club) и задайте его в `DEN_TOOKEN_KEY`
   (или введите в боковой панели, раздел «ИИ-анализ»).
2. Модель закреплена: `gpt-6-astra`. Если в кабинете она называется иначе, задайте точное имя в `DEN_TOOKEN_MODEL`.
   Модель не меняется из дашборда, чтобы прогнозы в журнале можно было сравнивать между собой.

Как устроен запрос:
- сводка начинается с текущего времени UTC, состояния основной сессии и возраста последней свечи;
  голоса индикаторов сведены по семействам; новости только за 24 часа, без дублей, 10 самых значимых;
  сигнал и план DEN стоят в самом конце с пометкой «для сравнения», чтобы модель не копировала готовый вывод;
- ответ проверяется: вход, стоп и цель должны быть уровнями из сводки или ценой (уровнем) ± k·ATR,
  стоп и цель по правильные стороны от входа, направление согласовано с вероятностью. Если проверка не
  прошла, модель получает список ошибок и отвечает ещё раз;
- делается 3 независимых запроса параллельно, итог по медиане вероятности (`DEN_AI_SAMPLES`, от 1 до 5).
  Это втрое больше токенов на один анализ;
- горизонт задаётся в `DEN_AI_HORIZON_H` (по умолчанию 4 часа).

Тон новостей модель оценивает двумя числами: насколько новость про актив (релевантность) и куда она
толкает цену; в запрос идёт возраст заголовка и несколько примеров оценки. Нерелевантные новости тон не двигают.

### Журнал прогнозов
Каждый ИИ-анализ записывается в `~/.den/ai_log.jsonl`: время, цена, вероятность роста, направление ИИ
и сигнал DEN в тот же момент. Когда горизонт прошёл, дашборд при открытии сверяет прогноз с ценой и
показывает во вкладке ИИ-анализа: сколько раз угадал ИИ, сколько DEN, сколько они вместе, и Brier score
вероятности ИИ рядом с наивной базой (всегда средняя частота роста). Если Brier ИИ не ниже базы, его
вероятность ничего не добавляет. Выводы имеют смысл после 50–100 прогнозов с исходом.

OpenRouter остался в коде для запуска вручную (`DEN_AI_PROVIDER=openrouter`, ключ в `DEN_OPENROUTER_KEY`),
но в дашборде больше не выбирается.

Осторожно: Tooken Club не официальный провайдер моделей. Независимые проверки посредников (veridrop.org)
находили, что расход токенов может считаться с завышением; GPT-модели проходили проверки лучше других.

## Уведомления в Telegram (по желанию)
По умолчанию выключены. Включаются, выключаются и настраиваются в любой момент в боковой панели дашборда,
раздел «Уведомления в Telegram»: переключатель, токен бота, chat id, активы, события, таймфреймы и период
проверки. После «Сохранить» настройки применяются сразу, перезапуск не нужен. Они хранятся в `~/.den/alerts.json`.

Бот пишет, когда:
- **сменился общий консенсус** (лонг, шорт или нейтрально);
- **совпали сигналы на таймфреймах** (по умолчанию 5m, 15m и 1h, все за лонг или все за шорт);
- **итоговый сигнал прошёл порог уверенности** (порог для уведомлений задаётся отдельно, по умолчанию 70%).

Как подключить:
1. В Telegram напишите @BotFather команду `/newbot` и скопируйте токен.
2. Вставьте токен в настройки уведомлений, нажмите «Сохранить», напишите своему боту любое сообщение,
   нажмите «Найти chat id», вставьте число в поле Chat id и снова «Сохранить».
3. Нажмите «Тест», включите переключатель и сохраните.

Пока открыт дашборд, проверки идут в нём. Чтобы уведомления шли и без дашборда, запустите
`python run_alerts.py` (в PyCharm: Run для `run_alerts.py`); он берёт те же настройки и тоже реагирует
на их изменение на ходу. Дважды одно и то же не придёт, даже если запущены оба. Из консоли:
`python run_alerts.py --on` / `--off` / `--test` / `--chat-id` / `--once`.
На первой проверке после включения бот только запоминает состояние и ничего не шлёт.

Каждый индикатор (EMA 9/21, EMA 50/200, MACD, RSI, Stochastic, ADX/DMI, Bollinger, OBV) голосует числом от −1 (шорт) до +1 (лонг) с весом. Средневзвешенный балл переводится в процент «за лонг». Общий консенсус усредняет таймфреймы, младшие весят больше.

Данные Yahoo Finance идут с задержкой до 10–15 минут. Это не инвестиционная рекомендация.

## Безопасность
- Дашборд слушает только `127.0.0.1` (`run.py` и `.streamlit/config.toml`): в нём настройки Telegram и ключ
  OpenRouter, поэтому из локальной сети он недоступен. Открыть для других устройств: `DEN_HOST=0.0.0.0 python run.py`,
  но тогда любой в сети сможет менять настройки и тратить лимит ключа.
- Токен бота хранится в `~/.den/alerts.json` с правами только для владельца (0600) и не отправляется в браузер:
  поле токена пустое, пустое значение при сохранении оставляет прежний токен. Из текстов ошибок токен вырезается.
- Ключи лучше задавать переменными окружения (`DEN_OPENROUTER_KEY`, `DEN_TOOKEN_KEY`, `DEN_TG_TOKEN`), а не коммитить: `.env` и
  `.streamlit/secrets.toml` в `.gitignore`.
- Заголовки новостей и ответы модели выводятся как Markdown без HTML. Заголовки уходят модели как данные; их автор
  теоретически может повлиять на вывод ИИ-анализа, поэтому вывод ИИ остаётся справочным.
