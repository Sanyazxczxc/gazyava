# DEN: анализ золота, серебра и AAPL

Дашборд для краткосрочной торговли: индикаторы, консенсус лонг/шорт по таймфреймам 5m, 15m, 1h и 1d, уровни поддержки и сопротивления, ориентиры стопа и целей по ATR.

## Запуск
```bash
python -m pip install -r requirements.txt
python run.py                 # то же, что streamlit run app.py; удобно для кнопки Run в PyCharm
streamlit run app.py          # реальные данные Yahoo Finance
DEN_DEMO=1 streamlit run app.py   # демо-режим на синтетических данных, без интернета
python -m den.analysis GC=F   # консенсус в консоли
python -m pytest -q           # тесты
```

## Как считается консенсус
Каждый индикатор (EMA 9/21, EMA 50/200, MACD, RSI, Stochastic, ADX/DMI, Bollinger, OBV) голосует числом от −1 (шорт) до +1 (лонг) с весом. Средневзвешенный балл переводится в процент «за лонг». Общий консенсус усредняет таймфреймы, младшие весят больше.

Данные Yahoo Finance идут с задержкой до 10–15 минут. Это не инвестиционная рекомендация.
